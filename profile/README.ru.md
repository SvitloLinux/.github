## Что это

Svitlo это минимальная графическая GNU/Linux-система собираемая целиком из исходного кода единым движком promin. Всё пользовательское пространство, от тулчейна (binutils, gcc, glibc), ядра, загрузчика и базовых утилит, через графику, сеть и wifi, до прикладных приложений, компилируется из исходников по декларативным рецептам

Загрузочный образ это композиция готовых store-пакетов (поколение профиля), а не отдельная фаза установки. В образ входят ядро, загрузчик, сетевой и wifi стек, и сам promin чтобы система умела управлять собой. Десктоп это COSMIC (libcosmic, Rust), чистый Wayland без единого X11-компонента в базе

Каждый бинарник прослеживается до своего исходника, версии и набора зависимостей через единый хеш. Система это Svitlo, пакетный менеджер это promin

## Пакетный менеджер (модель Nix)

promin следует модели Nix. Каждый пакет ставится в путь с хешем всех входов сборки

```
/promin/store/<hash>-<name>-<version>/
```

Хеш считается от исходника, версии, тела рецепта и хешей всех зависимостей. Разные версии или флаги дают разные пути, поэтому несколько версий сосуществуют без конфликта. Активное окружение это symlink-ферма (поколение профиля), переключение между поколениями атомарно, откат мгновенный

Хеш считается от канонического представления рецепта, а не от сырого текста, поэтому косметические правки не вызывают лишнюю пересборку

## Клиент и сервер

promin построен по схеме клиент-сервер. Тонкий сервер раздаёт рецепты, исходники и бинарные пакеты по хешу через HTTP. Сам сервер ничего не собирает. На установленной системе promin это клиент, install идёт binary-first

```
есть в store?  ->  локальный кеш?  ->  бинарь с сервера (по хешу)?  ->  сборка из исходников
```

Готовый бинарник верифицируется по sha256 до распаковки. Для пользователя это значит что пакеты скачиваются готовыми как в обычном дистрибутиве, а сборка из исходников остаётся инфраструктурным фактом на стороне сервера

## Для кого планируется дистрибутив

Образовательные учреждения, школы и университеты. ОС с открытой лицензией и набором сопутствующего софта. Воспроизводимость означает что учебная среда идентична до бита на всех машинах, а сломанная машина чинится за секунды откатом поколения

Государственный сектор. Аргумент это аудируемость цепочки поставки, каждый бинарник прослеживается до исходника через хеш без непроверяемых сторонних блобов, полное логирование действий пользователя и шифрование данных. Получение соответствующих сертификатов и лицензий планируется

Продавцы компьютеров и ноутбуков. ОС для предпродажной установки, с простой настройкой и инструментами для демонстрации характеристик процессора и видеокарты

Частные пользователи которые ценят простоту и надёжность с сильной защитой и приватностью

## Философия

Svitlo стремится быть простой, понятной, логичной, открытой и безопасной

- Простой и понятный интерфейс
- Очевидный и полезный набор софта
- Шифрование данных с уникальным ключом генерируемым при установке (планируется)
- Запрет трекинга и передачи любой аналитики из браузера или установленного софта (планируется)
- Система пригодная к работе сразу после установки, с мощным но простым пакетным менеджером для подгонки софта под пользователя

## Принципы

Сборка из исходников, полная воспроизводимость, прозрачность от исходника до бинарника. Минимализм против раздувания. Пользователь владеет всем стеком

## Состояние и охват

Целевое железо x86_64, это покрывает основную массу десктопов и ноутбуков. Поддержка ARM планируется следующим шагом. Десктоп это COSMIC на чистом Wayland, без X11 в базе (XWayland это опциональный пакет конечного пользователя). Система использует glibc
